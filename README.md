# เว็บไซต์พื้นหลังวิดีโอและตัวอักษร

เปิด `index.html` ในเบราว์เซอร์ได้ทันที หน้าแรกแสดงภาพวิดีโอที่หยุดนิ่งพร้อมเบลอเต็มจอและคำว่า `click here` โดยไม่มีการ์ด ตัวอักษร หรือปุ่มเสียงให้เห็น เมื่อคลิกหรือกด Enter/Space ที่คำนี้ จึงเริ่มภาพ เสียง และตัวอักษรพร้อมแสดงหน้าหลัก

## การ์ดโซเชียลที่เลื่อนซ้าย–ขวา

ลำดับคือ Instagram → Discord → Steam โดยเริ่มที่ Discord เลื่อนแบบ 3D โดยลากเมาส์ ปัดบนมือถือ แตะการ์ดด้านข้าง เลือกจุดด้านล่าง หรือกดลูกศรบนคีย์บอร์ดได้ ไม่มีปุ่มลูกศรซ้าย–ขวาบนหน้าจอ การ์ดที่ออกจะหมุนและถอยลึก ส่วนการ์ดใหม่เข้ามาด้านหน้า การ์ดที่ซ่อนจะไม่รับโฟกัส และปิดแอนิเมชันเมื่อเปิดโหมดลดการเคลื่อนไหว

ลิงก์ Instagram เชื่อมบัญชี `pxw_pxi_` และ Steam เชื่อม `76561198283913394` แล้ว เปลี่ยน URL ได้ใน `socialProfiles` ของ `js/social.js` และลิงก์สำรองใน `index.html` ไม่แสดงสถานะออนไลน์สมมติสำหรับสองแพลตฟอร์มนี้ โลโก้ทั้งสามใช้ SVG จากโครงการ Simple Icons (https://github.com/simple-icons/simple-icons) เก็บใน `assets/icons/`

## โปรไฟล์ Discord

การ์ดกลางจอเชื่อม `pawpai_` (User ID `705415549454385192`) ผ่าน Lanyard แล้ว มีรูปโปรไฟล์สำรองใน `assets/images/discord-avatar.webp` และดึงชื่อ รูป และสถานะล่าสุดอัตโนมัติ ไม่ใช้ Discord token ในหน้าเว็บ

สถานะอัปเดตทุก 15 วินาที แยกออนไลน์ ไม่อยู่ ห้ามรบกวน และออฟไลน์ หากเชื่อมต่อไม่ได้จะแสดงว่าไม่ทราบสถานะโดยไม่สรุปว่าออฟไลน์ พักการเรียกข้อมูลเมื่อซ่อนแท็บ และเชื่อมต่อใหม่เมื่อกลับมา

- `Video/background-loop.mp4` — คลิปตัดช่วงว่าง/ดำท้ายออก เหลือประมาณ 16.81 วินาที ภาพและเสียงเล่นวนซ้ำ
- `assets/images/video-poster.jpg` — ภาพแสดงระหว่างรอวิดีโอ
- `js/audio.js` — เล่นวิดีโอ เปิด–ปิดเสียง และพักเมื่อซ่อนแท็บ
- `js/music-curve.js` — กราฟความเร็วและเบสที่วิเคราะห์จากเสียงของคลิปนี้ทุก 25 มิลลิวินาที
- `js/background.js` — ตัวอักษรลอย เร่ง–ผ่อนตามตำแหน่งเวลาในคลิป พร้อมเอฟเฟกต์เมาส์
- `js/main.js` — แสงและการเอียงของกรอบกระจก
- `css/style.css` — วิดีโอเต็มจอ ไล่ความมืดบริเวณขอบ และจัดชั้นตัวอักษรกับกรอบ

วิดีโอเริ่มเล่นพร้อมเสียงที่ระดับ 45% หลังผ่านหน้า `click here` เท่านั้น หากเบราว์เซอร์บล็อกเสียงหลังคลิก จะลองเล่นแบบปิดเสียงและให้เปิดเสียงอีกครั้ง มีปุ่มเปิด–ปิดเสียงจางๆ ที่มุมซ้ายบน เมื่อกดปิดเสียงเองจะไม่เปิดซ้ำจากการคลิกที่อื่น ภาพกับตัวอักษรยังเคลื่อนไหวได้

ภาพและเสียงวนซ้ำด้วย video element เดียว ตัวอักษรอ่านกราฟจาก `currentTime` จึงกลับสู่จุดเริ่มต้นตามคลิป การซ่อนแท็บหรือพับหน้าต่างจะพักทั้งภาพและเสียง กลับมาจะเล่นต่อจากจุดเดิมและรักษาการตั้งค่าปิดเสียงไว้

ตัวอักษรสีขาวลดความทึบและลดความเด่นตรงกลางเพื่อไม่บังตัวละคร พื้นกระจกหม่นพร้อมเบลอบางๆ ไม่มีเส้นขอบด้านในกรอบ ไม่มีวงเมาส์หรือเส้นแสงตามเบส คลิกแตกครั้งละ 12 ตัว เว้น 250 มิลลิวินาที และจำกัดรวม 48 ตัว

หากเปลี่ยนวิดีโอ ให้สร้างกราฟใหม่ด้วยสคริปต์วิเคราะห์ใน `.preview/` โหมดลดการเคลื่อนไหวจะแสดงตัวอักษรนิ่ง

จุดวนใช้ภาพเฟรมแรกละลายทับช่วง 0.36 วินาทีสุดท้าย พร้อมเฟดเสียงสั้นๆ 55 มิลลิวินาทีที่หัวและท้ายเพื่อลดเสียงคลิก ไฟล์วิดีโอต้นฉบับยังอยู่ครบ




การ์ดด้านข้างแสดงจางๆ ที่ 28% และเบลอเล็กน้อย ส่วนการ์ดกลางชัดเต็มที่ รูปและชื่อ Instagram (🐼 / pxw_pxi_) และ Steam (gg) มาจากหน้าโปรไฟล์สาธารณะที่ผู้ใช้ให้มา เก็บรูปไว้ใน assets/images เพื่อไม่ให้ URL รูป Instagram หมดอายุ รูปและชื่อสองแพลตฟอร์มนี้เป็นข้อมูล ณ เวลาที่ดึง ไม่ใช่สถานะสดแบบ Discord


ชื่อแท็บใช้ชื่อแสดงผล Discord เดียวกับการ์ด และอัปเดตทุกครั้งที่ดึงโปรไฟล์สำเร็จ ไอคอนแท็บเป็นแก้วกาแฟ ASCII พื้นโปร่งใส สร้างด้วย Imagegen จากภาพอ้างอิง มีขนาด 32 และ 64 พิกเซลใน assets/icons เก็บภาพต้นฉบับและพรอมป์ต์ไว้ใน assets/images
